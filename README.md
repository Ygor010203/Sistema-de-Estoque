# 📦 Sistema de Controle de Estoque

Sistema desenvolvido em **Python (FastAPI)** no backend e **HTML/CSS/JavaScript** no frontend para gerenciamento completo de produtos, preços, quantidades e notas fiscais no estoque.

---

## 🚀 Tecnologias Utilizadas

* **Backend:** Python, FastAPI, SQLAlchemy, SQLite
* **Frontend:** HTML5, CSS3, JavaScript (Fetch API)
* **Controle de Versão:** Git e GitHub
