# 📦 Sistema de Controle de Estoque

> Sistema desenvolvido em Python para gerenciamento eficiente de estoque, integrando automações de processos e manipulação de planilhas.

## 🚀 Tecnologias Utilizadas

O projeto foi construído utilizando as seguintes tecnologias e ferramentas:
* **Python** (Linguagem principal)
* **SQLite / SQLAlchemy** (Banco de dados e ORM)
* **HTML / Web** (Interface do usuário)
* **Integrações:** Pipefy e Excel

---

## ⚙️ Funcionalidades

* **Gestão de Produtos:** Cadastro, atualização e controle de itens no estoque.
* **Controle de Notas Fiscais:** Registro detalhado vinculado às movimentações.
* **Automação:** Integração com planilhas Excel para importação/exportação de dados.
* **Fluxo de Processos:** Conexão com o Pipefy para acompanhamento de demandas.
